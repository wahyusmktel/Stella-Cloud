BAB III: Persiapan Server & Instalasi Web Server

Setelah berhasil login ke terminal Ubuntu kelompok Anda via Web SSH Stella Cloud, langkah pertama adalah memperbarui repositori paket dan memasang web server Apache beserta runtime PHP.

Langkah 1: Cek Alamat IP & Konektivitas Internet

Pastikan server kelompok Anda telah menerima IP DHCP dari sekolah dan dapat mengakses DNS internet:

BASHCek Jaringan & Koneksi
ip a
curl -I https://google.com

Langkah 2: Tambah Repositori PPA PHP 7.4

Sistem operasi Ubuntu 22.04 LTS membawa PHP 8.1 secara bawaan. Dikarenakan arsitektur aplikasi OwnCloud 10 membutuhkan runtime PHP 7.4 yang stabil dan kompatibel penuh, kita tambahkan repositori resmi PPA Ondřej Surý:

BASHUpdate Paket & Tambah PPA PHP
sudo apt update
sudo apt install -y software-properties-common
sudo add-apt-repository -y ppa:ondrej/php
sudo apt update

Langkah 3: Instalasi Apache2 Web Server & Ekstensi PHP 7.4

Pasang Apache web server bersama modul PHP 7.4 lengkap beserta driver basis data SQLite3:

BASHInstalasi Apache & Ekstensi PHP 7.4
sudo apt install -y apache2 libapache2-mod-php7.4 php7.4 php7.4-cli \
php7.4-common php7.4-sqlite3 php7.4-curl php7.4-gd php7.4-mbstring \
php7.4-xml php7.4-zip php7.4-intl unzip bzip2
💡
Pantau Telemetri: Saat proses instalasi paket di atas berjalan, lihat widget RAM VM dan CPU VM di pojok dashboard Stella Cloud Anda. Anda akan melihat grafik utilisasi bergerak real-time!

BAB IV: Deployment OwnCloud (Mode Hemat RAM via SQLite)

Kenapa Menggunakan SQLite? Database MySQL/MariaDB membutuhkan alokasi memori background sekitar 300–400 MB RAM. Dengan memilih SQLite, database disimpan langsung sebagai file lokal sehingga konsumsi RAM background adalah 0 MB (Server hanya mengonsumsi ~150 MB RAM total).

Langkah 1: Masuk ke Folder Sementara (/tmp) & Unduh Paket

Pindah ke direktori kerja sementara /tmp terlebih dahulu:

BASH1. Masuk ke folder /tmp
cd /tmp

Unduh file arsip resmi OwnCloud Server (disediakan Mirror Lokal Sekolah berkecepatan tinggi agar hemat kuota internet):

BASH2. Unduh Paket OwnCloud (Mirror Cepat Stella Cloud)
wget https://cloud.smktelkom-lpg.id/owncloud.tar.bz2 -O owncloud-complete-latest.tar.bz2

(Alternatif unduh langsung dari server luar: wget -c https://download.owncloud.com/server/stable/owncloud-complete-latest.tar.bz2)

Ekstrak paket OwnCloud ke direktori web server /var/www/:

BASH3. Ekstrak ke /var/www/
sudo tar -xjf owncloud-complete-latest.tar.bz2 -C /var/www/

Langkah 2: Konfigurasi Hak Akses (Permissions)

Web server Apache berjalan dengan user sistem www-data. Berikan hak kepemilikan folder ke user tersebut:

BASHSet Ownership & Permissions
sudo chown -R www-data:www-data /var/www/owncloud/
sudo chmod -R 755 /var/www/owncloud/

BAB V: Konfigurasi Virtual Host & Uji Akses Lokal

Langkah berikutnya adalah membuat berkas konfigurasi Virtual Host Apache agar server dapat langsung melayani permintaan web OwnCloud.

Langkah 1: Buat Konfigurasi Apache Virtual Host

BASHMembuat File Konfigurasi
sudo nano /etc/apache2/sites-available/owncloud.conf

Salin dan tempelkan konfigurasi berikut ke dalam editor nano:

APACHE CONFIG/etc/apache2/sites-available/owncloud.conf
<VirtualHost *:80>
    ServerAdmin admin@smktelkom-lpg.sch.id
    DocumentRoot /var/www/owncloud
    ServerName owncloud.local

    <Directory /var/www/owncloud/>
        Options +FollowSymlinks
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/owncloud_error.log
    CustomLog ${APACHE_LOG_DIR}/owncloud_access.log combined
</VirtualHost>

Simpan file dengan menekan Ctrl + O lalu Enter, kemudian keluar dengan Ctrl + X.

Langkah 2: Aktifkan Modul Rewrite & Virtual Host

BASHAktivasi Konfigurasi & Restart Apache
sudo a2enmod rewrite headers env dir mime
sudo a2dissite 000-default.conf
sudo a2ensite owncloud.conf
sudo systemctl restart apache2

Langkah 3: Inisialisasi Database SQLite & Akun Admin

Inisialisasi dapat dijalankan sangat cepat via CLI terminal menggunakan utilitas occ:

BASHInisialisasi Instan via OCC
sudo -u www-data php7.4 /var/www/owncloud/occ maintenance:install \
  --database "sqlite" --admin-user "admin" --admin-pass "smktelkom"
sudo -u www-data php7.4 /var/www/owncloud/occ config:system:set trusted_domains 1 --value="*"

(Atau buka browser ke http://10.219.30.xx/ untuk menyelesaikan via antarmuka grafis Web Wizard).

BAB VI: Integrasi Cloudflare Tunnel (Akses Internet)

Tahap akhir yang paling menarik dari praktikum ini adalah menghubungkan server lokal kelompok Anda ke internet publik tanpa memerlukan IP Publik statis ataupun setting port-forwarding di router sekolah, menggunakan teknologi Cloudflare Zero Trust Tunnel!

Langkah 1: Unduh Binary Cloudflared di Server

BASHDownload & Install Package Cloudflared
cd /tmp
curl -L --output cloudflared.deb https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb
sudo dpkg -i cloudflared.deb

Langkah 2: Menjalankan Quick Tunnel Publik (Instan)

Cloudflared memiliki fitur Quick Tunnel gratis yang secara otomatis memberikan alamat domain publik aman (HTTPS) dengan akhiran *.trycloudflare.com:

BASHJalankan Quick Tunnel
cloudflared tunnel --url http://localhost:80
Terminal Output — URL Publik Tunnel
+--------------------------------------------------------------------------------------------+
|  Your quick Tunnel has been created! Visit it at (it may take some time to be reachable):  |
|  https://random-subdomain-1234.trycloudflare.com                                                   |
+--------------------------------------------------------------------------------------------+

Langkah 3: Konfigurasi Trusted Domains pada OwnCloud

Secara default, OwnCloud akan memblokir akses jika dibuka melalui domain baru demi keamanan. Agar URL Cloudflare Tunnel diizinkan, jalankan perintah instan berikut via CLI:

BASHIzinkan Semua Domain Tunnel (Instan)
sudo -u www-data php7.4 /var/www/owncloud/occ config:system:set trusted_domains 2 --value="*"

(Atau jika ingin manual via editor: sudo nano /var/www/owncloud/config/config.php lalu tambahkan domain tunnel pada bagian 'trusted_domains').

Langkah 4: Pengujian Akses Internet dari Smartphone

  1. Matikan sambungan Wi-Fi di smartphone Anda dan beralihlah ke Paket Data Seluler (Internet Luar).
  2. Ketikkan URL https://random-subdomain-1234.trycloudflare.com di browser HP Anda.
  3. Login menggunakan akun admin OwnCloud yang tadi Anda buat.
  4. Coba lakukan Upload 1 File Foto dari galeri HP Anda ke server OwnCloud!
